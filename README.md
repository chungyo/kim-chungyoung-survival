# 김충영 서바이벌

일산의 어린 시절부터 개발자·AI 엔지니어·PM을 꿈꾸는 30살(진)까지, 다섯 시대를 지나는 픽셀 뱀서라이크 게임입니다. 실제 경험을 바탕으로 게임 속 적과 무기, 보스는 재미를 위해 창작했습니다. 다섯 시대의 맵, 주인공, 적 15종, 보스 5종과 무기 아이콘을 이 게임에 맞춰 새로 그렸습니다.

## 실행

이 폴더에서 아래 명령을 실행한 뒤 브라우저에서 `http://localhost:5180`을 엽니다.

```bash
python3 serve.py . 5180
```

- 방향키 또는 WASD: 이동. 공격은 자동입니다.
- 레벨업: 카드 클릭 또는 숫자 1·2·3.
- ESC: 일시정지.
- 제목 화면의 **시연하기**: 각 시대가 15초인 짧은 버전.
- 마지막 보스 **삼두의 마감**은 제한 시간까지 살아남으면 돌파합니다. 쓰러지면 해당 시대에서 다시 도전합니다.
- 클리어하면 한국어 자막과 음악을 담은 약 1분 18초의 엔딩 영상이 재생됩니다. 결과 보기로 건너뛰거나 결과 화면에서 다시 볼 수 있습니다. 브라우저가 자동 재생을 막으면 영상의 재생 버튼을 누르세요.

## 이야기

1. 일산과 알미공원: 인라인·자전거·발레·바이올린 콩쿠르.
2. 백석동에서 흑석동으로: 전교 1등과 경문고 시절의 롤.
3. 재수 이후 한양대 ERICA에서 프랑스어 공부.
4. 대통령 경호처에서 청와대 군 복무.
5. 가천대학교 AI 소프트웨어 공학과, MacBook 개발과 플래드랩스, 그리고 앞으로의 성장.

실제 연령을 추정해 표시하지 않고 시대 이름으로 표시합니다. 어린 시절 캐릭터는 안경을 씁니다.

## 엔딩 영상

영상 파일은 `assets/chungyoung-ending.mp4`입니다. AI 생성 일러스트는 `assets/ending/`에 보관하고, 배경 음악은 `scripts/create-ending.py`에서 합성했습니다. 영상 재생에 별도 설치는 필요하지 않으며, 영상 재생성에는 ffmpeg, Python NumPy와 macOS의 Apple SD Gothic Neo 글꼴이 필요합니다.

## 검증

```bash
node --test tests/*.test.mjs
```

일부 테스트는 브라우저 대신 최소 DOM/Canvas 모의 환경에서 게임 상태와 에셋 연결을 확인합니다. 실제 화면과 소리는 별도 브라우저 확인이 필요합니다.

개발용 `?bot&god&pause&demo`를 붙이면 자동 플레이를 준비하고 브라우저 콘솔의 `__sim(240)`으로 시연 흐름을 빠르게 확인할 수 있습니다.
